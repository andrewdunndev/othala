Audiobookshelf streams the family's audiobooks and podcasts — per-user progress, bookmarks, sleep timers, and offline downloads. There are official and community clients; the **native apps are excellent, so prefer them over the web player**. Sign in with your Othala account; the server URL is `https://listen.othala.test`.

## Android
Install the official **Audiobookshelf** app from the **[Google Play Store](https://play.google.com/store/apps/details?id=com.audiobookshelf.app)**. Add the server URL, sign in, done.

## iOS
The official **Audiobookshelf** iOS app is in **TestFlight** (Apple's beta program), so it's a two-step install:

1. Install **[TestFlight](https://apps.apple.com/app/testflight/id899247664)** from the App Store.
2. Open this invite to join the beta and install Audiobookshelf: **[testflight.apple.com/join/wiic7QIW](https://testflight.apple.com/join/wiic7QIW)**

The native app is excellent and worth the two steps. If you'd rather skip the beta, two great third-party iOS apps use Audiobookshelf as their backend: **[Plappa](https://plappa.me/)** and **[ShelfPlayer](https://github.com/rasmuslos/ShelfPlayer)**.

## Web
Any browser works at `https://listen.othala.test` — fine for a quick listen, but the native apps handle downloads and background playback far better.
