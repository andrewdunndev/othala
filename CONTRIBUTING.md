# Contributing

Issues and changes are welcome on either forge:
GitLab (canonical): https://gitlab.com/dunn.dev/othala (issues, merge requests)
GitHub (mirror): https://github.com/andrewdunndev/othala (issues, pull requests)
GitHub pull requests are landed through GitLab; the mirror then marks them merged.

Corrections are welcome: a false statement, a dead link, a config that does not do what it claims. Feature requests and changes that add configuration surface for a different deployment are not taken; fork it.
